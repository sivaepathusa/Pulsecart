# AI Use Log

## Tool Used

- ChatGPT

## What I Asked ChatGPT For

I asked for help with:

- Understanding the requirements and implementation approach for each station.
- Debugging Python and notebook errors.
- Clarifying statistical testing, p-values, correlation, and interpretation.
- Getting implementation and code-logic guidance for feature engineering, supervised models, and unsupervised clustering.
- Checking churn-model feature engineering and preventing data leakage.
- Reviewing clustering and time-series implementation approaches.
- Debugging the CNN training and holdout evaluation process.
- Developing and debugging regex patterns for extracting Order IDs, email addresses, and phone numbers from support-ticket `raw_message` text.

## How AI Was Used

ChatGPT was used as a support and debugging tool for implementation questions, code logic, troubleshooting, and clarification of concepts.

The analysis, code execution, results, and final conclusions were checked using the provided PulseCart dataset before being included in the project.

## What I Did Not Use AI For

- I did not use external datasets.
- I did not submit AI-generated results without verification.
- I did not rely on AI-generated results without running the analysis on the provided dataset.
